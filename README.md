# Backend на Go

![Title](title.png)

Быстрый и наполненый курс про бекенд разработке на языке `go`. 
На первых занятиях будет краткое введение в `go`, 
после этого студентам расскажут о `HTTP`, веб-разработке, СУБД и разворачивание своего кода через `docker` и `docker-compose`.

Канал курса в [Телеграм](https://t.me/itam_go_course).
